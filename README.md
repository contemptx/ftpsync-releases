# FTPSYNC Releases

Official public distribution repository for FTPSYNC desktop releases.

This repository is reserved for installers, packaged applications, release notes and signed update metadata. FTPSYNC application source code is maintained separately in a private repository and must not be uploaded here.

## Release status

No public installer has been published yet. The desktop application is undergoing release qualification. Signed automatic updates are planned; they are not available from this empty release feed yet.
